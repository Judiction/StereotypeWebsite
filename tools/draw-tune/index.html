About Paint Tune

Paint Tune

Draw lines on the canvas. A tempo line sweeps left to right; wherever it crosses a line, that line sings. Height is pitch, colour is waveform.

Vibe-coded by BE A STEREOTYPE. If you like this, consider following on Instagram and sharing what you created!

Built with the Web Audio API and Tone.js.
